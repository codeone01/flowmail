# Skill: ui-ux

## Quando Usar

Use em melhorias de formulario, inbox, metricas e tarefa.

## Objetivo

Criar uma experiencia clara de triagem de e-mails.

## Regras

- Mobile first.
- Feedback para classificar, selecionar, copiar e exportar.
- Estados vazio, erro e sucesso.
- Contraste, foco visivel e area de toque adequada.
- Nao prometer integracao real inexistente.

## Passos

1. Validar fluxo em mobile.
2. Revisar hierarquia visual.
3. Garantir textos objetivos.
4. Testar controles principais.

## Checklist

- [ ] Nada sobreposto.
- [ ] Tarefa gerada legivel.
- [ ] Inbox escaneavel.

## Evite

- Interface generica de SaaS sem relacao com e-mail.
- Animacoes excessivas.
